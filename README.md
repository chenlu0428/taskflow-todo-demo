# TodoList 待办事项管理（原生JS项目）
## 项目简介
纯原生JavaScript开发的待办任务管理应用，采用面向对象Class封装、数据驱动视图模式，无任何第三方框架。
可用于展示原生JS数组处理、DOM封装、本地持久化、表单交互、筛选搜索等前端基础能力。

## 技术栈
HTML5 + CSS3 + ES6 原生JavaScript + LocalStorage本地存储

## 核心功能
1. 任务CRUD：新增、双击编辑、删除、标记完成状态；包含空值校验、重复任务拦截
2. 多条件筛选：全部/未完成/已完成三Tab切换 + 关键词实时搜索
3. 批量操作：一键全部完成、一键清空已完成任务
4. 优先级管理：高/中/低三级优先级，颜色区分展示
5. 数据持久化：自动保存到LocalStorage，刷新浏览器数据不丢失
6. 数据统计：总任务数、剩余未完成数量、任务完成率自动计算
7. 响应式布局，适配电脑端与移动端，增删改带有过渡动画

## 项目亮点
1. 代码采用面向对象封装，杜绝全局变量污染，结构模块化
2. 严格遵循数据驱动视图：只修改数组数据，统一渲染页面
3. 大量使用数组方法：filter、map、reduce，体现JS数据处理能力
4. 完善边界处理：空输入、重复内容、编辑为空自动删除、防误删确认
